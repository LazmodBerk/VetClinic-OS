**VetClinic OS**, veteriner klinikleri için tasarlanmış, **modern, hızlı ve yapay zeka destekli** açık kaynaklı bir klinik yönetim ve müşteri (hasta) portalı ekosistemidir. Geleneksel yazılımların aksine, kullanıcı deneyimi (UX) ön planda tutularak *glassmorphism* ve yenilikçi tasarım prensipleriyle (Orman Yeşili & Toprak tonları) geliştirilmiştir.

## ✨ Öne Çıkan Özellikler

### 🏥 Klinik Yönetim Paneli (Admin Dashboard)
- **Hasta & Randevu Yönetimi:** Evcil hayvan bilgilerini, geçmiş ziyaretleri, alerjileri ve kan gruplarını kolayca takip edin.
- **Finans & Muhasebe:** Gelir-gider tablolarını grafiksel (Recharts) olarak inceleyin, hızlı fatura oluşturun.
- **Envanter & Stok:** Kritik stok seviyelerindeki ürünleri takip edin.
- **Yapay Zeka (AI) Asistan & Aşı Tahmini:** Geçmiş verilere dayanarak gelecek ayki ilaç/aşı ihtiyaçlarını tahmin eden AI modülü. Doğal dilde komutlarla klinikle ilgili bilgilere erişin.

### 📱 Hasta Portalı (Müşteri Yüzü)
- **Modern Landing Page:** Kliniğinizi tanıtan, randevu alınabilen şık bir web sitesi arayüzü.
- **Müşteri Paneli:** Hasta sahiplerinin kendi evcil hayvanlarının aşı geçmişini, laboratuvar sonuçlarını inceleyebileceği premium portal.
- **Tele-Sağlık (Canlı Görüşme):** Hekimlerle uygulama üzerinden görüntülü iletişim altyapısı.

## 🚀 Kurulum & Çalıştırma

Projeyi yerel bilgisayarınızda çalıştırmak için aşağıdaki adımları izleyin:

```bash
# 1. Repoyu bilgisayarınıza klonlayın
git clone https://github.com/your-username/VetClinic-OS.git

# 2. Proje klasörüne girin
cd VetClinic-OS/frontend

# 3. Bağımlılıkları yükleyin
npm install

# 4. Geliştirme sunucusunu başlatın
npm run dev
```

Tarayıcınızda `http://localhost:5173` adresine giderek projeyi görüntüleyebilirsiniz.
- **Panel (Admin):** `/`
- **Web Sitesi (Landing):** `/website`
- **Hasta Portalı:** `/portal`

## 🎨 Tasarım Prensipleri (Design System)
Proje, sıradan beyaz/mavi klinik yazılımlarından sıyrılıp, güven ve profesyonellik veren bir renk paletine sahiptir:
- **Primary:** Deep Forest Green (`#1B4332`)
- **Accent:** Soft Sage (`#95D5B2`)
- **Secondary:** Terracotta (`#E07A5F`)
- **Tipografi:** Başlıklar için `Playfair Display` (Serif), gövde metinleri için `DM Sans` (Sans-serif).
